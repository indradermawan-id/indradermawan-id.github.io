# Indra Dermawan

## Tentang Saya

Perkenalkan, saya **Indra Dermawan**, seorang yang memiliki ketertarikan besar terhadap teknologi informasi, pengembangan sistem, pengolahan data, serta pemanfaatan teknologi untuk membantu pekerjaan menjadi lebih efektif dan terstruktur.

Saat ini saya berkiprah sebagai **Operator Sistem Informasi Administrasi Kependudukan** di **Dinas Kependudukan dan Pencatatan Sipil Kabupaten Simeulue**. Dalam pekerjaan sehari-hari, saya berhadapan dengan sistem informasi, data, aplikasi, serta berbagai kebutuhan operasional yang membutuhkan ketelitian dan kemampuan dalam menggunakan teknologi.

Bagi saya, teknologi bukan hanya tentang membuat aplikasi atau menulis kode. Teknologi adalah alat untuk menyelesaikan masalah, menyederhanakan pekerjaan, mengelola informasi dengan lebih baik, dan memberikan manfaat nyata bagi orang lain.

## Perjalanan Pendidikan

Ketertarikan saya terhadap dunia komputer membawa saya menempuh pendidikan **D-III Teknologi Komputer di LP3I Banda Aceh**. Pendidikan tersebut menjadi salah satu fondasi penting dalam memahami dunia teknologi informasi dan komputer.

Saya kemudian melanjutkan pendidikan ke jenjang **S1 Informatika di Universitas Ubudiyah Indonesia Banda Aceh**. Melalui pendidikan tersebut, saya semakin memperluas pemahaman mengenai informatika, pemrograman, sistem informasi, pengolahan data, serta bagaimana teknologi dapat diterapkan untuk menyelesaikan berbagai kebutuhan.

## Pengalaman

Sebelum menjalani pekerjaan saya saat ini, saya memiliki pengalaman sebagai **Guru IT** dan **Operator Komputer**.

Pengalaman sebagai Guru IT memberikan saya kesempatan untuk berbagi pengetahuan dan membantu orang lain memahami teknologi. Sementara pengalaman sebagai Operator Komputer mengajarkan saya pentingnya ketelitian, konsistensi, pengelolaan data, dan kemampuan beradaptasi dengan berbagai kebutuhan pekerjaan.

Berbagai pengalaman tersebut kemudian menjadi bekal yang saya gunakan dalam pekerjaan sebagai Operator Sistem Informasi Administrasi Kependudukan.

## Ketertarikan di Bidang Teknologi

Saya memiliki ketertarikan pada pengembangan aplikasi web, sistem informasi, pengolahan data, serta teknologi yang dapat membantu proses kerja menjadi lebih efisien.

Beberapa teknologi yang saya gunakan dan pelajari antara lain:

- PHP
- Laravel
- JavaScript
- Python
- MySQL
- SQL Server
- Bootstrap

Saya terus berusaha mengembangkan kemampuan tersebut karena dunia teknologi selalu berubah. Bagi saya, belajar bukan sesuatu yang berhenti setelah menyelesaikan pendidikan, tetapi merupakan proses yang terus berjalan.

## Proyek yang Pernah Saya Kerjakan

Salah satu proyek yang pernah saya kerjakan adalah **SIAP (Sistem Informasi Agenda Pelayanan) Disdukcapil Simeulue**.

Proyek tersebut berangkat dari kebutuhan nyata dalam lingkungan pelayanan administrasi kependudukan. Saya tertarik untuk memanfaatkan teknologi agar proses yang sebelumnya membutuhkan pengelolaan secara manual dapat dibuat lebih terstruktur melalui sistem informasi.

Selain itu, saya juga pernah mengembangkan **Sistem Administrasi Sekolah**, yang dibuat untuk membantu proses pengelolaan administrasi di lingkungan sekolah.

Bagi saya, nilai sebuah aplikasi bukan hanya terletak pada teknologi yang digunakan, tetapi pada seberapa besar aplikasi tersebut dapat membantu menyelesaikan masalah yang benar-benar ada.

## Pelatihan dan Pengembangan Diri

Untuk terus meningkatkan kemampuan, saya juga mengikuti berbagai pelatihan, di antaranya:

- Pelatihan Dasar CPNS
- Pelatihan Pengolahan Data
- Pelatihan Dasar-Dasar Komputer
- Pelatihan Penggunaan AI

Saya tertarik dengan perkembangan **Artificial Intelligence (AI)** karena teknologi ini membuka banyak kemungkinan baru dalam pekerjaan, pengolahan informasi, otomasi, dan pengembangan solusi digital.

## Prinsip Saya

Saya percaya bahwa kemampuan teknologi akan semakin bernilai ketika digunakan untuk memberikan manfaat.

Karena itu, saya berusaha untuk tidak hanya belajar bagaimana sebuah teknologi bekerja, tetapi juga memahami **masalah apa yang ingin diselesaikan**, siapa yang akan menggunakan solusi tersebut, dan bagaimana teknologi dapat dibuat sesederhana mungkin untuk membantu pekerjaan.

Saya juga percaya bahwa proses belajar tidak pernah selesai. Setiap proyek, pekerjaan, kesalahan, dan pengalaman baru merupakan kesempatan untuk berkembang.

## Ke Depan

Ke depan, saya ingin terus meningkatkan kemampuan di bidang **pengembangan sistem informasi, web development, pengolahan data, dan Artificial Intelligence**.

Saya ingin menghasilkan lebih banyak solusi digital yang praktis, mudah digunakan, dan memiliki manfaat nyata, khususnya dalam mendukung digitalisasi pekerjaan dan pelayanan publik.

Website ini saya buat sebagai ruang untuk memperkenalkan diri, mendokumentasikan perjalanan saya di bidang teknologi, serta membagikan beberapa karya dan proyek yang pernah saya kerjakan.
